# Что в бутылке, кроме вина?

Интерактивная учебная страница о нематериальных активах ПАО «Абрау-Дюрсо». Шесть практических разделов, мини-игра, антикризисный сценарий и 12 вопросов для другой группы.

Сайт статический: достаточно открыть `index.html` или разместить файлы в корне репозитория GitHub Pages. Источники и оговорки приведены на странице.
