# Нематериальные активы «Абрау-Дюрсо»

Информативно-интерактивная презентация для студентов в роли инвесторов: шесть практических разделов, сравнение управленческих вариантов, 12 уточняющих вопросов другой группе и отдельный блок из шести вопросов аудитории с ориентирами ответов.

Сайт статический: достаточно открыть `index.html` или разместить файлы в корне репозитория GitHub Pages. Источники и оговорки приведены на странице.
