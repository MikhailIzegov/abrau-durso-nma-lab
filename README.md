# Нематериальные активы «Абрау-Дюрсо»

Информативная презентация для выступления о НМА компании: шесть практических разделов с короткими выводами и финальный блок простых вопросов к аудитории. Интерактивные элементы помогают раскрыть примеры и сравнить варианты работы с правами.

Сайт статический: достаточно открыть `index.html` или разместить файлы в корне репозитория GitHub Pages. Источники и оговорки приведены на странице.
